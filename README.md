### What I learned

In this assignment, I tried to work with a rule like @media.

```css
@media (max-width: 400px) {
    .card {
        width: 340px;
    }

    .card-img {
        width: 300px;
    }
}
```

### Continued development

Ultimately: find out how to do without @media and adjust the content so that it fits the width of the screen.
